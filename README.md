# Lupa

AI-powered educational platform designed to analyze student engagement through facial expression recognition in real time.

## 🚀 Overview

Lupa is a mobile application built with React Native that integrates a custom-trained AI model to detect and analyze facial expressions during classes.

The goal of the project is to provide educational institutions with behavioral insights that help improve student engagement and learning outcomes.

The application is designed as a social-style platform for academic environments, allowing institutions to monitor and analyze participation trends.

---

## 🧠 Core Features

- 📱 Cross-platform mobile app (iOS & Android)
- 🤖 Integration of custom-trained facial expression recognition model
- 📊 Real-time engagement analysis
- 🔐 User authentication system
- 🗂 Structured and scalable frontend architecture
- 🌐 Backend API integration
- 📈 Data visualization and analytics layer

---

## 🏗 Architecture

The project follows a modular architecture with separation of concerns:

- UI Components Layer
- State Management Layer
- API & Data Handling Layer
- AI Model Integration Layer

Frontend built with:

- React Native
- TypeScript
- Redux (state management)
- REST API integration

The AI model processes facial expression data and returns structured engagement metrics consumed by the application.
